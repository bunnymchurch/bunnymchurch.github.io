# Technical Writing Portfolio

A responsive, documentation-style portfolio starter built with HTML, CSS, and a small amount of JavaScript. It can be hosted directly from a GitHub Pages repository without a build step, theme dependency, or paid service.

## Before publishing

1. Search the project for `Your Name`, `your.email@example.com`, and bracketed prompts such as `[Add ...]`.
2. Replace those placeholders with accurate professional information.
3. Review every sample. The Atlas product and its API are fictional examples created for demonstration; keep that disclosure or replace the content with work you can share.
4. Add only tools, skills, and accomplishments you can substantiate.
5. Check all navigation links and contact links.

## Publish with GitHub Pages

1. Create a GitHub account at https://github.com/join if you do not have one.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
3. Upload the contents of this folder to the repository root. Upload the files and folders themselves, not the enclosing ZIP or folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait for the Pages deployment to finish. Visit `https://YOUR-USERNAME.github.io`.

GitHub Pages publishing can take several minutes after the first save. If the site does not appear, check the **Actions** tab and the Pages settings for deployment status.

## Suggested final checks

- Test the site on a phone and desktop.
- Check spelling, punctuation, terminology, and heading hierarchy.
- Confirm that code examples are clearly marked as fictional and are not presented as production API contracts.
- Do not publish confidential client or employer material.
- Add a custom domain later if you own one; it is not required.

## Files

- `index.html`: portfolio landing page
- `about.html`: professional profile
- `skills.html`: tools and capabilities
- `contact.html`: contact details
- `samples/`: four writing samples
- `assets/css/styles.css`: layout and visual styling
- `assets/js/site.js`: mobile navigation and current-year footer
