Getting started with Atlas

Set up your workspace and create your first project.

Audience: New usersContent type: Quick-start guideProduct: Fictional sample
Sample note: Atlas is a fictional project-management product created to demonstrate documentation structure and writing technique.

Overview

Atlas helps teams organize work in projects. This guide explains how to create a workspace, invite a teammate, and add your first project.

Before you begin

  • You need access to an Atlas account.
  • Have the email addresses of any teammates you want to invite.

1. Create your workspace

  1. Sign in to Atlas.
  2. On the welcome screen, select Create a workspace.
  3. Enter a workspace name. Choose a name your team will recognize.
  4. Select Create workspace.

Expected result: Atlas opens the new workspace and displays the workspace dashboard.

2. Invite a teammate

  1. Open Workspace settings.
  2. Select Members, then select Invite member.
  3. Enter the teammate’s email address.
  4. Choose an access role, then select Send invitation.

Expected result: The teammate appears in the member list with an invitation pending.

3. Create your first project

  1. From the workspace dashboard, select New project.
  2. Enter a project name and an optional description.
  3. Select Create project.

Expected result: Atlas opens the project overview. You can now add tasks and assign work.

Next steps

  • Troubleshoot common workspace issues.
  • Review your workspace members and access roles.
  • Create tasks to break the project into manageable work.

Writing decisions demonstrated

  • Task-based title and clear audience.
  • Prerequisites presented before the procedure.
  • Numbered steps use concise imperative verbs.
  • Expected results help readers confirm success.
